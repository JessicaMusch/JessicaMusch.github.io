Townsmen - A Kingdom Rebuilt

Townsmen - A Kingdom Rebuilt is a medieval strategy and city-builder game, where you build your own empire from the ground up. Providing basic infrastructure for the Townies and collecting necessary resources to expand the city.

This game allows the Player to choose between challenging Scenarios or relaxing Sandbox experiences, only interrupted by occasional bandits!

  • Time: 6 months
  • Team: 7
  • Engine: in-house
  • Platform: Mobile
  • Other Tools: Confluence, Visual Studio Code
